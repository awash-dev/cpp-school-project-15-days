## Important Notes

- **Terminal Compatibility**: All code and status messages have been converted to plain text (no emojis) to ensure visibility on all terminal emulators.
- **Windows Optimization**: The Day 7 ATM System uses `conio.h` and `_getch()` for secure, hidden password inputs on Windows systems.
- **Persistence**: Application data is stored in human-readable CSV formats (e.g., `bank_data.txt`) to simulate real-world database interactions.
